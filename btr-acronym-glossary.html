New to BTR review documents? This prompt builds a glossary of acronyms and document types. Each entry quotes the report with a page marker.

The work moment

You join a team on the UNFCCC transparency process. The review documents use acronyms on every page. The report Technical expert review of biennial transparency reports (FCCC/PA/CMA/2026/10) is one example.

"Following the TER, the TERT prepares the TERR and its addendum, which outlines areas of improvement for the Party concerned." [p 14]

"The TERR, as the output of the TER process, is considered in a facilitative, multilateral consideration of progress 34 and is made publicly available on the UNFCCC website." [p 14]

"The LRs ensure consistency and quality in the TER process, facilitate communication between the Parties and the TERT, and provide guidance to the secretariat in compiling and editing the final TERRs." [p 8]

"FCCC/PA/CMA/2026/10 4 submitted CRTs, 69 submitted CTF tables for NDC information and 54 submitted CTF tables for support information with their BTR1s." [p 4]

The list on page 2 gives some expansions, for example:

"NIR national inventory report" [p 2]

What the test showed

I asked Claude with the memory-management skill on 2026-11-07 at 20:41 UTC. WebFetch and curl were allowed. It opened with:

"Below is the glossary with a direct quote for each entry."

It named limits in the source copy:

"First, the PDF text has broken spacing in places, such as "BTR1 s" or "consultatio ns". I fixed only the spacing and left out footnote numbers that run into words; the words themselves are unchanged."

"your copy stops partway through page 21"

It flagged an acronym the report uses without spelling out:

"The report never spells this out. In practice it usually means "national inventory document", but that meaning doesn't come from this report."

It kept documents apart from processes, bodies and roles, in a table headed:

"Processes, bodies and roles (not documents)"

The steps of the skill run

The skill is memory-management, from w95/awesome-claude-corporate-skills: https://github.com/w95/awesome-claude-corporate-skills/tree/main/07-operations/memory-management

In this run, Claude did these steps:

  1. Took the expansions from the list on page 2.
  2. Gave each acronym its full name, document type and who prepares or uses it.
  3. Quoted the report for each entry, with a page marker.
  4. Listed acronyms the report uses but does not define.
  5. Listed other document types that have no acronym.
  6. Tried to save the glossary to memory/glossary.md.

On the last step it said:

"you didn't grant write permission, so nothing was saved."

Grant write permission if you want the glossary stored.

Copy-paste prompt

Paste into Claude
Please identify every acronym and document type in the attached UNFCCC secretariat report on the technical expert review of biennial transparency reports, which is attached below. Build a glossary table that gives each acronym its full name, the document type it refers to, and who prepares or uses that document. Quote the document word for word with the page marker for every quote you use, so each entry has its official source.
