# BTR Checklist

One country situation in, one checklist out. Each line names the decision and paragraph it comes from. A date that no opened document states is marked unverified.

**Inputs**
- `country`: optional. Matters only for whether it is a least developed country (LDC) or small island developing State (SIDS), and whether it is a developing country Party applying flexibility.
- `report`: which BTR, e.g. the second.

## Why this exists

BTR questions get answered from slides and blog posts that mix the old biennial update reports with the new framework, and that state deadlines without saying where they come from. A deadline in a brief needs a decision number and a paragraph, or it needs the word unverified next to it.

## Sources (use these and nothing else)

| Document | What it holds | File |
|---|---|---|
| Decision 1/CP.21, FCCC/CP/2015/10/Add.1 | Para 90, how often Parties report under Article 13 | `https://unfccc.int/resource/docs/2015/cop21/eng/10a01.pdf` |
| Decision 18/CMA.1 and its annex (the MPGs), FCCC/PA/CMA/2018/3/Add.2 | Decision para 3 (first BTR date), para 4 (LDC and SIDS discretion). MPG paras 5 and 6 (flexibility), para 10 (what a BTR contains), paras 11 to 16 (format and submission), para 58 (latest inventory year), para 198 (late submission) | `https://unfccc.int/sites/default/files/resource/CMA2018_03a02E.pdf` |
| UNFCCC page for the report in question | The secretariat's statement of the due date and the list of submissions | `https://unfccc.int/second-biennial-transparency-reports` (for BTR2) |
| Paris Agreement, Article 13 | The paragraphs 7 to 10 the decisions refer to. The Agreement is the annex to decision 1/CP.21 | Same file as decision 1/CP.21 |

The UNFCCC site often serves a bot check instead of the page. The PDFs usually open with a plain download. If a page does not open, say so and do not fill it from memory or a search summary.

## Steps

1. Open both decision PDFs. Copy each document symbol and its date from the first page.
2. Find the due date. Quote decision 18/CMA.1 para 3 for the first BTR and decision 1/CP.21 para 90 for the frequency.
3. For a later BTR, open the UNFCCC page for that report and quote its date. If the page does not open, write the date as derived from the two paragraphs above and mark it `UNVERIFIED: not stated in an opened document`.
4. Build the checklist from MPG para 10, one line per sub-paragraph, keeping the decision's own verb. "Shall" is required. "Should" is expected. Do not turn a "should" into a must.
5. Add the format and submission lines from MPG paras 12, 15 and 16, the inventory year rule from para 58, and the LDC and SIDS line from decision para 4 and MPG para 11.
6. If the country is a developing country Party, add the flexibility rule from MPG para 6 in one line.

## Answer layout

```
<report> · sources read <today's date>
Due: <date>   "<quoted line>"   <decision>, para <n>     (or UNVERIFIED and why)
Frequency:    "<quoted line>"   decision 1/CP.21, para 90

| # | Item | Shall or should | Source |
|---|---|---|---|
| 1 | <item in the decision's words> | shall | MPG para 10(a) |
| ... | | | |

Not covered: <anything asked about that the opened documents do not state>
```

## Rules

- **A date with no paragraph behind it is `UNVERIFIED`. Never give a deadline from memory, a news item or a search result summary as confirmed.**
- Quote the decision's words for every item. Shorten only by cutting, never by paraphrase that changes "shall" or "should".
- Keep BTRs apart from national communications and from biennial update reports. They are different reports under different decisions.
- If the question asks about a tool, a template or a table the opened documents do not describe, write `NOT IN SOURCE` and name the document that would hold it, if known.
- Never invent a number of tables, pages or chapters.

For each item, give the decision paragraph and say whether the text says "shall" or "should". For the due date, quote the paragraph or page that states it. # Claim Check

A draft and its sources in, one row per sentence out. A sentence passes only when a line in the source says the same thing on the page the draft cites.

**Inputs**
- `draft`: up to about 15 sentences. Number them if they are not numbered.
- `sources`: the documents the draft cites, as links or files. Official UN documents only (see below).

## Why this exists

A reviewer checks the number and the page. A checker that reads from memory, or matches only the numbers, passes a sentence whose figure sits on another page or belongs to another sentence. Long UN reports repeat the same percentages for different subjects, so a number found on the right page is not yet a match.

## Sources (use these and nothing else)

- The documents the user gives, if they are published by the UN system: documents with a UN symbol (A/..., E/..., FCCC/...) from `documents.un.org` or the publishing office, and reports on `un.org`, `unstats.un.org` or a UN agency's own site.
- Nothing else. Do not confirm a sentence from memory, from a news story or from a different edition of the same report.
- A source the user names but you cannot open is not a source. Every sentence that cites it gets `NOT IN SOURCES` with the note "could not open".

## Steps

1. Open each source. Copy its symbol or title and its date as printed on the first page.
2. Work out how the document numbers its pages. Use the page number printed on the page. Say so if it differs from the PDF page count.
3. For each sentence, go to the page or section it cites. Look for a line that states the same claim: the same figure, the same year, the same unit and the same subject.
4. If the cited page has no such line, search the whole source. If the line is on another page, the verdict is `WRONG PAGE` and the row gives the right page.
5. If no page in any source has the line, the verdict is `NOT IN SOURCES`. Quote the closest line, if there is one, so the reader sees what the source does say.
6. Fill one row per sentence. Never merge two sentences into one row.

## Verdicts

| Verdict | Means |
|---|---|
| SUPPORTED | A line on the cited page states the same figure, year, unit and subject |
| WRONG PAGE | The line exists in the source but not on the page the draft cites |
| NOT IN SOURCES | No line in any source states it. This includes a figure that differs from the source by any amount |

A number that matches but belongs to a different subject is not support. A share of adults with a bank account does not support the same share of people with electricity.

## Answer layout

```
Source: <symbol or title>, <date as printed> · <URL> · read <today's date>
Pages: <printed page numbers | PDF page numbers>

| # | Sentence | Source | Page/section | Quoted line | Verdict |
|---|---|---|---|---|---|
| 1 | <first words of the sentence> | <symbol> | p. <n>, para <n> | "<line, word for word>" | SUPPORTED |
| 2 | ... | ... | cited p. <n>, found p. <m> | "<line>" | WRONG PAGE |
| 3 | ... | ... | cited p. <n> | closest: "<line>" or none | NOT IN SOURCES |

<n> of <total> supported.
```

## Rules

- **Cannot open a source: say which one and mark its sentences NOT IN SOURCES with "could not open". Do not judge them from memory.**
- Quotes are word for word. If text extraction breaks spacing, fix only the spacing.
- Never round, convert or recompute a figure to make it match. A source that says 12% does not support 13%.
- Do not rewrite the draft. The table says what is wrong, the author fixes it.
- Do not add sources the draft did not cite. If a better source exists, say so in one line under the table.

## Copy-paste prompt (works in any assistant)

> Check my draft against its sources, one sentence at a time. For each sentence, open the source and the page it cites, and give me a table: sentence, source, page or section, the line from the source word for word, and a verdict. The verdict is SUPPORTED only if a line on the cited page states the same figure, year and subject. If the line is on another page, write WRONG PAGE and give the right page. If no line in the source says it, write NOT IN SOURCES and quote the closest line. Do not judge any sentence from memory. If you can't open a source, say so for every sentence that cites it.

# Metadata Read

One indicator code in, six quoted fields out, always in the same order. Every field says which section of the metadata it came from, and the section heading is copied as the PDF writes it.

**Input**
- `code`: an indicator code from the global SDG indicator framework, e.g. `3.1.1`

## Why this exists

The wrong denominator is the most common way a correct number gets misread. The maternal mortality ratio in 3.1.1 is per 100,000 live births, and the metadata itself warns that the maternal mortality rate, a different measure, divides by person-years lived by women of reproductive age.

In a recorded test without this skill, Claude got most of the 3.1.1 wording right and still put the custodian under `1.a "Organisation"`. The PDF names it in 0.g. Its 3.1.1 limitations were about vital registration and sibling histories, while 4.b of the PDF is about the ratio and the rate. For 6.1.1 it gave `Denominator (4.c): The total population.` Section 4.c of the 6.1.1 PDF never says what is divided by what.

## Sources (use these and nothing else)

| What | Where |
|---|---|
| Metadata PDF | `https://unstats.un.org/sdgs/metadata/files/Metadata-<CC-TT-II>.pdf`. Each part of the code becomes two digits, so 3.1.1 becomes `03-01-01` and 6.1.1 becomes `06-01-01` |
| Index of metadata files, if the PDF link fails | `https://unstats.un.org/sdgs/metadata/` |

Do not use a WHO, UNICEF or World Bank page, a textbook, a news story or a summary from memory, even when it agrees.

## Steps

1. Open the PDF. Copy the `Last updated` date from the page header and the template line (`Harmonized metadata template - format version 1.1` or the like).
2. Find each field under its section. In the harmonized template these are:

| Field | Section |
|---|---|
| Definition | `2.a. Definition and concepts (STAT_CONC_DEF)` |
| Unit | `2.b. Unit of measure (UNIT_MEASURE)` |
| Numerator and denominator | No section of its own. Look in 4.c first, then 2.a |
| Method of computation | `4.c. Method of computation (DATA_COMP)` |
| Limitations | `4.b. Comment and limitations (REC_USE_LIM)` |
| Custodian | `0.g. International organisations(s) responsible for global monitoring (SDG_CUSTODIAN_AGENCIES)` |

3. Copy each section heading exactly as the PDF prints it, spelling included (`organisations(s)` is the PDF's own spelling). If the PDF uses an older template with other numbers, copy its headings and say so.
4. Quote the first sentence of the definition, the whole unit line and the first sentence of the limitations. For the method, quote the first sentence in 4.c that says how the value is computed. If 4.c opens with a list of production steps, skip it and take the sentence with the rule, such as the 6.1.1 line that the service level is "taken as the minimum of these three indicators". Fix only spacing broken by text extraction (`t aken` becomes `taken`).
5. For numerator and denominator, quote the one sentence that says what is divided by what. If no sentence in the PDF names both, write `NOT IN SOURCE` and quote the unit line instead. Do not build a fraction from the definition.

## Answer layout

```
<code> · <indicator name from 0.c>       metadata last updated <date>, <template line>
Definition      "<quote>"                          <section heading>
Unit            "<quote>"                          <section heading>
Numerator and denominator  "<quote>" or NOT IN SOURCE    <section heading>
Method          "<quote>"                          <section heading>
Limitations     "<quote>"                          <section heading>
Custodian       "<quote>"                          <section heading>
Source: <PDF URL> · read <today's date>
```

## Rules

- **Cannot open the PDF: say "I can't open the metadata now" and give the link. Do not fill any field from memory.**
- The order of the six fields never changes, even when the question asks about one of them.
- A field the PDF does not have is `NOT IN SOURCE`. Never fill it from another indicator, another agency or what the field usually says.
- Never convert a unit. Per 100,000 live births stays per 100,000 live births. Do not restate it as a percent or per woman.
- When the PDF names a similar measure that uses a different denominator, add one line quoting that sentence with its section. For 3.1.1 that is the maternal mortality rate in 4.b.
- Never invent a number. Every number in the answer appears in the PDF.

## Copy-paste prompt (works in any assistant)

> Open the official UN metadata PDF for SDG indicator <code> at unstats.un.org/sdgs/metadata (the file is Metadata-CC-TT-II.pdf, so 3.1.1 is Metadata-03-01-01.pdf). Give me, in this order: definition, unit of measure, numerator and denominator, method of computation, limitations, custodian agency. Quote each one word for word and copy the section heading it sits under. If the PDF never says what is divided by what, write NOT IN SOURCE for that line. If you can't open the PDF now, say so and give me the link. Do not answer from memory.

# Reference Year Check

One table in, the same table back with a database year next to every value. A table that compares countries is only fair when every value is from the same year and the same population.

**Inputs**
- `table`: CSV or pasted rows with a country column and a value column. A year column is optional.
- `code`: the SDG indicator code the values claim to be, e.g. `6.1.1`. If the table does not say, ask.

## Why this exists

Comparison tables are built over weeks from several downloads. Each value was "latest" on the day it was copied, so one table can hold several years and still carry one year in its header. The database also holds partial rows. For some countries the only rows for a series are urban or rural, and a value copied from them reads like a national figure.

## Sources (use these and nothing else)

| What | Where |
|---|---|
| Series codes for the indicator | `https://unstats.un.org/sdgapi/v1/sdg/Indicator/List`, the entry for the exact code |
| Country codes | `https://unstats.un.org/sdgapi/v1/sdg/GeoArea/List` |
| Values with years | `https://unstats.un.org/sdgapi/v1/sdg/Series/Data?seriesCode=<SERIES>&areaCode=<M49>&pageSize=1000` |

Do not use an agency portal, a report table or memory to find a year. The years in this check come from `timePeriodStart` in the database rows.

## Steps

1. Find the series for the code. If there are several, ask which one the table uses, or check each and say so.
2. Get the M49 code for every country in the table, using the names as the database writes them.
3. Pull every row for each country. Keep the total rows (`ALLAREA`, `BOTHSEX`, `ALLAGE` where those dimensions exist). Note when a country has no total row.
4. For each table value, find the database year whose value matches it. Round the database value to the table's number of decimals before comparing, and never round the table value.
5. Take the year most rows share as the table's reference year. Flag every row that differs from it, every row that matches only a partial row, every row with no match and every empty cell.
6. For each flagged row, also give the database value for the reference year, if there is one, so the author can replace it.

## Answer layout

```
<code> · series <SERIES> · SDG Global Database, read <today's date>
Reference year: <year> (<n> of <total> rows)

| Country | Table value | Table year | Database year of that value | Row used | Database value for <ref year> | Flag |
|---|---|---|---|---|---|---|
| <country> | <v> | <y> | <year> | ALLAREA | <value> (<nature>) | OK |
| <country> | <v> | <y> | <year> | ALLAREA | <value> (<nature>) | YEAR DIFFERS |
| <country> | <v> | <y> | <year> | URBAN only | NOT IN SOURCE for national | PARTIAL ROW |
| <country> | <v> | <y> | no match | ALLAREA | <value> (<nature>) | NO MATCH |
| <country> | empty | <y> | none | none | NOT IN SOURCE | NO DATA |

<n> rows flagged.
```

## Rules

- **Cannot reach the API: say "I can't check the database now", give the link and flag nothing. Do not guess years.**
- A row with no total in the database is `NOT IN SOURCE` for the national value. Never use an urban or rural value in its place, and never average urban and rural.
- A value that matches no year is `NO MATCH`. Do not pick the nearest year.
- If two years round to the same table value, list both years and flag the row.
- Keep the `Nature` attribute (estimated, modelled, country data) next to every database value.
- Never fill an empty cell. Report what the database has for it, or `NOT IN SOURCE`.

## Copy-paste prompt (works in any assistant)

> Here is a country comparison table for SDG indicator <code>. For every row, look up the country in the UN SDG Global Database (unstats.un.org/sdgapi, Series/Data) and tell me which year the value in my table belongs to. Use only the national total row. Tell me if a country has only urban or rural rows. Give the year most rows share, and flag every row from another year, every value that matches no year and every empty cell. For each flagged row, give the database value for the shared year. Do not guess any year from memory. If you can't open the database now, say so.

# SDG Indicator Card

Two inputs, one card. Every line on the card says where it came from.

**Inputs**
- `code`: an indicator code from the global SDG indicator framework, e.g. `6.1.1`
- `country`: a country name as the SDG Global Database writes it, e.g. `Ghana`

## Why this exists

An assistant asked for an indicator value from memory gives a number, a rough year and a hedge. In a recorded test without this skill, Claude said Ghana's 6.1.1 figure was "about 38%" for "around 2022". The SDG Global Database read on 20 October 2026 has 42.9 percent for 2024, estimated. For Kenya it said "somewhere around 30–40%". The database has no Kenya row for the series `SH_H2O_SAFE` at all.

## Sources (use these and nothing else)

| What | Where | Cite as |
|---|---|---|
| Definition, custodian, method | `https://unstats.un.org/sdgs/metadata/files/Metadata-<CC-TT-II>.pdf` (6.1.1 becomes `06-01-01`) | `metadata <code> §<section>, last updated <date>` |
| Series list for the code | `https://unstats.un.org/sdgapi/v1/sdg/Indicator/List` | `SDG API, Indicator/List` |
| Country code | `https://unstats.un.org/sdgapi/v1/sdg/GeoArea/List` | `SDG API, GeoArea/List` |
| Values | `https://unstats.un.org/sdgapi/v1/sdg/Series/Data?seriesCode=<SERIES>&areaCode=<M49>&pageSize=1000` | `SDG Global Database, <SERIES>, <year>` |

## Steps

1. Open the metadata PDF. Copy the **last updated** date from the page header.
2. Copy the custodian agencies from **§0.g** and the first sentence of the definition from **§2.a**, word for word.
3. Read **§4.c** (computation), **§4.f** (missing values) and **§4.g** (aggregation). Pick the one rule a reader is most likely to get wrong. Quote it word for word with its §.
4. Get the series codes for the indicator, then the country's rows for each series.
5. Use the total row (`ALLAREA`, `BOTHSEX`, `ALLAGE` where those dimensions exist). Report the latest year, the value, the unit and the `Nature` attribute (estimated, modelled, country data).

## Card layout

```
<code> · <official indicator name>
<country> · <value><unit> (<year>, <nature>)        SDG Global Database, <SERIES>
Definition   "<first sentence of §2.a>"             metadata §2.a, <last updated>
Custodian    <agencies>                              metadata §0.g
The catch    "<quoted rule>"                         metadata §4.x
Source       <source field of the data row>
```

## Rules

- **No value in the database: write `NOT IN SOURCE` and say which series was empty.** Never fill it from a news story, a report or a guess.
- Never average, sum or convert values. If the method says how a figure is built, quote that sentence instead.
- If an indicator has several series, list each series code. Do not choose one silently.
- Take series only from the entry for the exact code in `Indicator/List`. A series filed under a neighbouring code, such as `SH_SAN_HNDWSH` under 6.2.1, is not a series of 6.1.1.
- Quotes are word for word. If the PDF text is broken by extraction (`t aken`), fix only the spacing.
- Keep the `Nature` label. An estimated or modelled value is not the same as country-reported data.

## Copy-paste prompt (works in any assistant)

> For SDG indicator <code> in <country>, take the value only from the UN SDG Global Database (unstats.un.org/sdgapi) and the definition and custodian only from the official metadata PDF (unstats.un.org/sdgs/metadata). Quote the definition word for word with its section number. Give the year, the unit and whether the value is estimated, modelled or country data. If the database has no row for this country, write NOT IN SOURCE and name the empty series. If you can't open these pages now, say so and give me the links instead of a number. Do not answer from memory.

# UN Latest Edition

One question in, one answer that says which edition it came from. A figure without an edition is not an answer.

**Inputs**
- `report`: a UN flagship report, e.g. `Human Development Report`
- `figure`: what is wanted, e.g. `HDI for Ghana`

## Why this exists

Flagship reports come out every year or two, and each edition recomputes past years. An assistant answering from memory tends to give the numbers of the edition it saw in training and call them current. In a recorded test, Claude without this skill named the 2025 Human Development Report and quoted the 2023/24 edition's Ghana figures.

## Sources (use these and nothing else)

The publisher's own page for the report, then the data file linked from that page. Start here:

| Report | Publisher | Where the edition is listed |
|---|---|---|
| Human Development Report | UNDP | `https://hdr.undp.org/data-center/documentation-and-downloads` |
| Sustainable Development Goals Report | UN DESA | `https://unstats.un.org/sdgs/report/<year>/` |
| World Population Prospects | UN DESA Population Division | `https://www.un.org/development/desa/pd/` |
| State of Food Security and Nutrition in the World | FAO, IFAD, UNICEF, WFP, WHO | `https://www.fao.org/publications/fao-flagship-publications/the-state-of-food-security-and-nutrition-in-the-world/en` |
| World Economic Situation and Prospects | UN DESA | `https://desapublications.un.org/publications/` |
| World Health Statistics | WHO | `https://www.who.int/data/gho/publications/world-health-statistics` |
| State of the World's Children | UNICEF | `https://www.unicef.org/reports/state-of-worlds-children` |
| Employment and Social Trends | ILO | `https://www.ilo.org/research-and-publications` |
| World Investment Report | UNCTAD | `https://unctad.org/topic/investment/world-investment-report` |
| State of the Global Climate | WMO | `https://wmo.int/publication-series/state-of-global-climate` |

For the HDI the data file is the composite indices time series CSV linked from the downloads page
(`HDR25_Composite_indices_complete_time_series.csv` for the 2025 edition). The value is in column `hdi_<year>`, the rank in `hdi_rank_<year>`.

## Steps

1. Open the publisher's page. Find the newest edition and its publication date. Copy the line that shows both, word for word.
2. Follow that page to the edition's data file or report. Do not use a file from another edition, even for older years. Editions recompute the past.
3. Read the figure from the file. Note the column or table and the row.
4. Answer in this order: edition, publication date, figure, where in the file, source URL, date you read it.

## Answer layout

```
<report> <edition> (published <date>, "<line from the publisher's page>")
<figure>: <value>                           <file>, <column or table>, <row>
Source: <URL> · read <today's date>
```

## Rules

- **Cannot open the page or the file: say "I can't check the current edition" and give the link. Do not give a number.**
- Never answer from memory, even with "about" or "I believe". A remembered figure is from an unknown edition.
- The edition year is not the publication year. The 2025 State of the Global Climate came out in 2026. Copy both as the page writes them.
- If you remember a different figure, say which edition you think it came from, then give the current one from the file.
- Do not mix editions in one table. If a reader needs a time series, take every year from the same file.

## Copy-paste prompt (works in any assistant)

> Before you give any figure from a UN report, tell me which edition it comes from and when that edition was published. Read the publisher's own page and the current data file first. If you can't open them now, say "I can't check the current edition" and give me the link instead of a number. Do not answer from memory.

## Running it as code

`engines/ai/reports_table.py` in the claude-for-sdg repository opens each publisher page above, keeps a copy with its SHA-256 and keeps a row only when the edition and date are written on the page.
`engines/ai/hdi_card.py` reads the current and the previous HDR CSV side by side.
